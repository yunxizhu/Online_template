# 拉斯岛

2–5 人联机桌游。先到 **10 分** 获胜。

## 地图结构

公共地图分三大区，各有 **1–6 数字格**：

| 区域 | 每轮摆放 | 上限 |
|------|----------|------|
| 资源 | `6+n` | 12 |
| 功能 | `2+n` | 6 |
| 建筑 | `1+n` | 6 |

`n = 轮次 - 1`。卡牌依次放入 1→6，超出回绕（第 7 张再放 1 号格）。

## 牌堆与弃牌

资源 / 功能 / 建筑各有**抽牌堆**与**旁置弃牌堆**：

- 轮次回收、用完的功能卡、弃置的功能/未建造建筑 → 进入对应**弃牌堆**（不立刻塞回抽牌堆底）
- 抽牌时若抽牌堆空了，将该类**弃牌堆洗混**后作为新抽牌堆

## 派遣与结算

- 生产时把**同一点数的全部骰子**派到某一大区的**对应数字格**（不是点某一张小卡）
- 结算时按「大区 + 数字格」汇总村民并抵消
- **资源格**：最多者获得该格上**所有资源卡的大份**之和；第二获得**所有小份**之和
- **功能/建筑格**：最多者拿走该格上全部对应卡

## 流程概览

1. **先手**（仅第 1 轮）：全员投骰比大小  
2. **生产** → **结算** → **建造** → **轮次结束** → 回收重摆  

## 动作一览

| type | 说明 |
|------|------|
| `initRoll` | （已改为开局自动投骰宣布先手，再发牌） |
| `produceRoll` | 生产回合手动投掷（空闲村民数=骰子数） |
| `placeDice` | `{ face, area }` 或 `{ face, buildingId }`；遥控模式另可带 `{ count }` |
| `voidSkip` | 虚空派遣 1 名村民并结束本回合 |
| `useFunc` | 功能卡；投掷前用 `remoteDice` 进入遥控模式；`banditRaid` 在指定大区数字格放置 2 枚中立骰（抵消/占名次）；`expand` 获得时自动发动（+1 无数字格） |
| `voidSkip` | 虚空派遣 |
| `exchange` | 已建交易所：任意时间，`n` 个相同资源 → 任意 1 个；`n` 随自己持有座数：1→4、2→3、3→2、≥4→1；无需工人、无限次 |
