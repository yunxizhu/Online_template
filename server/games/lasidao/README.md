# 拉斯岛

2–5 人联机桌游。先到 **15 分** 立刻获胜（唯一赢家；建造阶段按回合顺序）。

## 地图结构

公共地图分 **资源区** 与 **功能/建筑合区**，各有 **1–6 数字格**：

| 区域 | 每轮摆放 | 上限 |
|------|----------|------|
| 资源 | `6+n` | 18 |
| 功能/建筑合区 | `2+n` | 6 |

`n = 轮次 - 1`。卡牌依次放入 1→6，超出回绕。资源区每数字格最多 3 张，未解锁格位显示「第 n 轮解锁」。合区 2、4、6 号格暗置。

## 开局

每人 **3 名村民**、**3 间房子**（每间房子 1 分，开局 **3 分**），**无初始资源**。自动投骰决定先手（平局重投），宣布后发牌进入第 1 轮。村民上限 **15**。

## 牌堆与弃牌

资源与**功能/建筑合堆**各有抽牌堆与旁置弃牌堆：

- 功能卡与建筑卡开局混洗为合堆；牌堆顶公开下一张类型（功能/建筑）
- 轮次回收、用完的功能卡、弃置的功能/未建造建筑 → 进入合堆弃牌
- 抽牌时若抽牌堆空了，将该类弃牌堆洗混后作为新抽牌堆

## 流程概览

1. **先手**（仅第 1 轮）：全员自动投骰比大小  
2. **生产** → **结算** → **个人产出**（资源建筑自动产出）→ **结算行动（弃牌）** → **许愿井**（若有）→ **建造** → **轮次结束** → 回收重摆  

## 派遣与结算

- 生产时把**同一点数的全部骰子**派到某一大区的**对应数字格**
- 结算时按「大区 + 数字格」汇总村民并抵消
- **资源格**：最多者获得该格上**所有资源卡的大份**之和；第二获得**所有小份**之和
- **功能/建筑格**：最多者拿走该格上全部对应卡
- **资源建筑**：建成后在个人产出阶段自动产出，无需工人

## 个人产出与弃牌

结算动画结束后、弃牌判定前：
- **资源建筑**自动产出对应资源（产出后若超手牌上限，再进入弃牌）

弃牌处理完毕后、建造阶段开始前：
- 若有已建成**许愿井**：所有拥有者**同时**选择资源（每座 +1 任意资源），全部确认后进入建造  

建造阶段内再获得的资源即使超过手牌上限也不再强制弃牌。

## 常驻功能（建造阶段，不限次数）

- **建造房子**：3 木 3 石 2 铁 → 房子 +1、+1 分  
- **繁殖村民**：小麦消耗 = 当前村民数 → +1 村民（上限 15）；需至少 1 间空闲房子（空闲 = 房子 − 村民；开局 3 房 3 村民）

## 动作一览

| type | 说明 |
|------|------|
| `produceRoll` | 生产回合手动投掷（空闲村民数=骰子数） |
| `placeDice` | `{ face, area }`；遥控模式另可带 `{ count }` |
| `voidSkip` | 爆掉 1 枚未派遣骰子，获得任意 1 资源，结束本回合 |
| `useFunc` | 功能卡；`banditRaid` 放置 2 中立骰；`expand` 三栏一并扩建 |
| `allocateWishWell` | 许愿井阶段：`{ alloc: { wood, stone, food, iron } }` |
| `exchange` | 默认银行 4:1；集市 1→3:1、2→2:1、≥3→1:1 |
| `buildHousePermanent` / `breedPermanent` | 常驻建造/繁殖 |
