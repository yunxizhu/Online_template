# 拉斯岛

2–5 人联机桌游。先到 **15 分** 立刻获胜（唯一赢家；建造阶段按回合顺序）。

## 地图结构

公共地图分三大区，各有 **1–6 数字格**：

| 区域 | 每轮摆放 | 上限 |
|------|----------|------|
| 资源 | `6+n` | 18 |
| 功能 | `2+n` | 6 |
| 建筑 | `1+n` | 6 |

`n = 轮次 - 1`。卡牌依次放入 1→6，超出回绕。资源区每数字格最多 3 张，未解锁格位显示「第 n 轮解锁」。功能/建筑区 2、4、6 号格暗置。

## 牌堆与弃牌

资源 / 功能 / 建筑各有**抽牌堆**与**旁置弃牌堆**：

- 轮次回收、用完的功能卡、弃置的功能/未建造建筑 → 进入对应**弃牌堆**
- 抽牌时若抽牌堆空了，将该类**弃牌堆洗混**后作为新抽牌堆

## 流程概览

1. **先手**（仅第 1 轮）：全员自动投骰比大小  
2. **生产** → **结算** → **结算行动** → **个人产出**（资源建筑自动产出；有许愿井则并行选资源）→ **建造** → **轮次结束** → 回收重摆  

## 派遣与结算

- 生产时把**同一点数的全部骰子**派到某一大区的**对应数字格**
- 结算时按「大区 + 数字格」汇总村民并抵消
- **资源格**：最多者获得该格上**所有资源卡的大份**之和；第二获得**所有小份**之和
- **功能/建筑格**：最多者拿走该格上全部对应卡
- **资源建筑**：建成后在个人产出阶段自动产出，无需工人

## 个人产出

结算行动结束后、建造阶段开始前：
- **资源建筑**自动产出对应资源  
- 若有已建成**许愿井**：所有拥有者**同时**选择资源（每座 +1 任意资源），全部确认后进入建造 

## 常驻功能（建造阶段，不限次数）

- **建造房子**：3 木 3 石 2 铁 → +1 分  
- **繁殖村民**：小麦 = 当前村民数 → +1 村民（上限 12）

## 动作一览

| type | 说明 |
|------|------|
| `produceRoll` | 生产回合手动投掷（空闲村民数=骰子数） |
| `placeDice` | `{ face, area }`；遥控模式另可带 `{ count }` |
| `voidSkip` | 丢弃 1 个指定资源并结束本回合 |
| `useFunc` | 功能卡；`banditRaid` 放置 2 中立骰；`expand` 扩容建筑格或功能卡格 |
| `allocateWishWell` | 许愿井阶段：`{ alloc: { wood, stone, food, iron } }` |
| `exchange` | 默认银行 4:1；集市 1→3:1、2→2:1、≥3→1:1 |
| `buildHousePermanent` / `breedPermanent` | 常驻建造/繁殖 |
