Dlaczego C++?

Język C++ jest odpowiednim rozwiązaniem dla mojego zadania, ponieważ:
  • Windows API jest napisane w C i dokumentacja MSDN dotyczy tego języka.
  • Dzięki programowaniu obiektowemu z dziedziczeniem, można elegancko zaimplementować współpracę róznych algorytmów sztucznej inteligencji.
  • C++ umożliwia uzyskanie szybkiego kodu dla niskopoziomowych operacji, które występują przy wykonywaniu, cofaniu i analizowaniu ruchów. Teoretycznie lepszy mógłby być assembler, jednak wiązałoby się to z utratą przejrzystości programu.

Co można ulepszyć?

  • W praktyce gry z ludźmi przez internet okazało się, że przydałby się mechanizm pospieszania komputera, gdy myśli zbyt długo. Można to uzyskać wykonując algorytm minimax dla kolejnych głębokości przeszukiwania i w momencie, gdy użytkownik nakaże przerwać obliczenia, algorytm zwróci najlepszy ruch z ostatniego ukończonego przeszukiwania.
  • Można dalej starać się dobrać lepsze tablice heurystyczne określające punktowanie sytuacji i oszacowania wartości ruchów.
  • Wprowadzić bibliotekę debiutów.
  • Umożliwić komputerowi analizowanie sytuacji w osobnym procesie, podczas gdy człowiek zastanawia się nad ruchem.
