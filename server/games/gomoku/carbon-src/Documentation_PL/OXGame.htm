Klasa OXGame

Pliki

OXGame.cpp, OXGame.h

Opis

Klasa OXGame przechowuje i udostępnia informacje o stanie gry, umożliwia wykonywanie, cofanie ruchów oraz wykrywanie zakończenia.

Metody publiczne

MetodaOpis
OXGame()
Konstruktor 
void    start(int bsize = 19)
Rozpoczyna nową grę na planszy o rozmiarze bsize. Wykonywany jest pierwszy ruch na środku planszy. 
bool    move(int x, int y)
Wykonuje ruch (x, y). Zwraca true w przypadku zakończenia gry. 
void    undo()
Cofa ostatni ruch. 
OXPiece cell(int x, int y) const
Zwraca zawartość komórki (x, y), lub WRONG w przypadku przekroczenia zakresów. 
bool    isWinPoint(int x, int y) const
Czy pole (x, y) należy do wygrywającej piątki? 
int     moveCount() const
Zwraca liczbę ruchów. 
int     boardSize() const
Zwraca rozmiar planszy.

Zwraca ostatni ruch. 
OXPiece player() const
Zwraca aktualnego gracza. 
bool    finished() const
Zwraca true wtedy i tylko wtedy, gdy gra jest zakończona. 
OXPiece winner() const
Zwraca zwycięzcę; EMPTY w przypadku braku zakończenia.
