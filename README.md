# 联机大厅框架

Node.js + Socket.IO 回合制联机骨架，支持：

- 大厅 / 公开房间 / 隐藏房间（房间码）
- **跨网联机（唯一联机方式）**：MQTT 固定广播 + Cloudflare 隧道进房（已取消局域网 UDP 发现，本机/局域网同样走隧道），见 [`docs/mqtt-bulletin-README.md`](docs/mqtt-bulletin-README.md)
- 谁建房，房间就开在谁的进程上（房主即主机）
- **五子棋**：创建房间时选择游戏；大厅列表显示游戏类型；15 路棋盘，五子连珠获胜
- **印加宝藏**：3–8 人；同时抉择「继续/返回」，全员锁定后才揭晓并翻牌结算（选择彼此不可见）
- **三国杀**：已实现「标准身份」（5/8）、「2V2」（4）、「1V2」（3）；主公/交叉/地主规则与标准牌效果；武将技能（除 1V2 专属）后续再补

## 启动

**一键启动（Windows）**：双击 [`启动.bat`](启动.bat)  
**本机双开测联机**：双击 [`本机双开测试.bat`](本机双开测试.bat)

或用命令行：

```bash
npm install
npm start
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

### 同一台电脑测「两个人」

开两个终端，用不同端口各起一个实例：

```bash
# 终端 A（房主）
set PORT=3000
npm start

# 终端 B（加入方）
set PORT=3001
npm start
```

然后：

- A 打开 `http://localhost:3000`
- B 打开 `http://localhost:3001`
- A 创建公开房间 → 约 1～2 秒后 B 的「公开房间」列表会出现该房间 → 点加入（自动经 Cloudflare 隧道连到 A）

PowerShell：

```powershell
$env:PORT=3000; npm start
# 另一个窗口：
$env:PORT=3001; npm start
```

### 同一 WiFi / 不同网段 / 外网好友（同一套机制）

所有实例统一走 MQTT 广播 + Cloudflare 隧道：启动后自动连 `broker.emqx.io`，登录即上报在线，建房后同步隧道地址；加入房间与对局一律经隧道连接（本机多开、局域网、跨网均相同）。详见 [`docs/mqtt-bulletin-README.md`](docs/mqtt-bulletin-README.md)。

## 隐藏房

隐藏房不会出现在列表里，但房间码仍通过 MQTT 广播解析。对方输入房间码即可自动连到房主。

## 目录

```
server/index.js           # Express + Socket.IO
server/rooms.js           # 房间逻辑
server/mqttBulletin.js    # MQTT 广播（唯一联机发现通道）
server/tunnel.js          # Cloudflare 快速隧道
  server/games/             # 游戏注册表 + 各游戏服务端
  index.js                # 统一注册（新增游戏只改这里 + 加文件夹）
  gomoku/                 # 五子棋（含 smoke/）
  incan/                  # 印加宝藏（含 smoke/）
  sgs/                    # 三国杀（规则 + 模式 + smoke/）
public/                   # 大厅壳
  games/<id>/             # 各游戏前端：panel.html / ui.js / style.css / 资源
scripts/                  # 框架级脚本（冒烟测试等）；游戏冒烟有兼容转发入口
```

新增游戏时：在 `server/games/<id>/` 实现规则并导出 `client` 资源路径；在 `public/games/<id>/` 放面板与 UI；冒烟测试放 `server/games/<id>/smoke/`；再在 `server/games/index.js` 注册即可。

## 五子棋规则（已实现）

- 双人，15×15 棋盘
- 房主先手执黑，后加入者执白
- 轮流落子，横/竖/斜连成 5 子即胜；棋盘下满为平局

## 三国杀（标准身份 · 已实现基础）

- 仅支持 **5 / 8 人** 满员开局；模式入口预留「国战 / 1v1」等后续扩展
- 身份配置、主公亮明、主公 5 选 1 / 其余 3 选 1（标准武将池，主公体力 +1）、起手 4 张
- 回合六阶段、座位距离 / 攻击范围 / ±1·+1 马
- 基本牌、标准锦囊、装备的核心结算（杀闪桃、拆顺、南蛮万箭、决斗借刀、乐闪、武器防具等）
- 濒死求桃、反贼击杀摸 3、主公误杀忠臣弃光
- **尚未实现**：武将技能、无懈可击连锁完整窗口、军争扩展牌；部分武器特效为简化版

## 三国杀（2V2 · 已实现）

- **4 人**满员；座位 1·4 同阵营，2·3 同阵营（交叉坐）
- 忠/反随机分配到两队；消灭对方两人即胜
- 双方各 8 将池 → 每人 Ban 对方 1 将 → 再从己方池选将（无主公技/无主公体力+1）
- 起手 4 张；**4 号位起手 5 张**；**1 号位首回合摸牌 -1**
- **队友手牌互相可见**；队友阵亡后存活方摸 1 张补偿

## 三国杀（1V2 · 已实现）

- **3 人**叫地主：可叫 1/2/3 倍或不叫；叫 3 直接当地主；全不叫则首位以 1 倍当地主
- 主公 5 选 1，反贼各 3 选 1；主公体力 +1，坐 1 号先手
- 主公专属：**跋扈**（准备阶段多摸 1，出杀次数 +1）、**飞扬**（判定阶段可弃 2 手牌拆 1 判定牌）
- 一名反贼阵亡：另一反贼选摸 2 或回 1 血；主公死则反贼胜，反贼全灭则主公胜
- 牌堆含【兵粮寸断】（距离 1）

- 3–8 人，共 5 座神庙
- 每位仍在探险的玩家同时选择「继续探险」或「返回营地」；锁定前他人看不到你的选择
- 全员锁定后揭晓：返回者结算通道宝石（仅 1 人返回时可带走神器）；继续者翻 1 张探索卡
- 同种灾难卡出现第 2 张则坍塌，探险中玩家丢失随身宝石（帐篷内已锁定不受影响）
- 5 座神庙结束后，帐篷宝石 + 神器分最高者胜；同分比神器数量

## 后续打成 EXE

每个 EXE 启动时附带拉起本进程的 server；建房方就是主机，其它 EXE 通过 MQTT 看到房间并经 Cloudflare 隧道 Socket.IO 连过去。
