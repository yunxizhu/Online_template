一、各兵种 × 各阶

规则：几何机械风 —— 全部硬边多边形块面 / 折线液压杆 / 平行散热格栅 / 铆钉点阵 / 菱形能量核 / 带齿履带，方头尖角，笔笔是机加工零件。 机体一律方形构图：碰撞与命中判定是正方形（size 格见方），长条 / 细长剪影会误导玩家，所以半长 / 半宽压到接近 1:1，武器（炮管 / 喷臂 / 镜筒）只从方框里探出一小截。 六种机体各有骨架（锐士＝双足突击机甲、盾卫＝履带重装堡垒、游侠＝三足炮塔平台、轰击＝自行迫击炮车、燎原＝喷火机甲、激光兵＝光束发射车）， 阶数 = 机体多焊上去的部件 —— 初级只留认得出型号的骨架；中级加散热格栅 / 液压支腿 / 加强环 / 稳定鳍；高级再加推进器 / 副炮管 / 电池匣 / 副镜管 / 装甲裙板。进化体型按 1 / 1.5 / 2 放大，多出来的面积正好摆这些新部件。
