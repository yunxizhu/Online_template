# MQTT 固定广播（默认跨网发现）

启动后自动连到公共 MQTT，把「谁在线 / 房间隧道」低频写上去；别人订阅同一频道即可看到。进房与对局走 Cloudflare 隧道。

```text
登录 → MQTT 上报在线（10s 心跳）
建房 → MQTT 上报房间 + 隧道地址（10s 心跳）
别人看到列表 → 点加入 → 直连隧道对局
```

默认无需任何配置。固定服务器：`broker.emqx.io`（EMQX 公共 broker）。

## 可选

| 文件 / 环境变量 | 作用 |
|----------------|------|
| `mqtt.off`（空文件）或 `MQTT_BULLETIN=0` | 关闭 MQTT 广播 |
| `mqtt.channel` 一行文字，或 `MQTT_CHANNEL` | 小群隔离频道（默认 `xiyun_lianjidating_public`） |
| `mqtt.broker` 或 `MQTT_BROKER` | 换成自己的 MQTT 地址 |

同一频道的人才能互相看见。若不想和所有用这个游戏的人挤在一起，把同一串频道名发给朋友即可（仍不用填服务器地址）。

## 说明

- MQTT 是订阅推送，不是 HTTP 轮询；消息一到就会更新本地列表
- 仅识别带有本程序签名的 MQTT 消息；普通 MQTTX 测试消息不会出现在大厅里
- 人员若超过 15 秒未收到新心跳，则视为下线
- 房间若超过 15 秒未收到房主新心跳，则视为消失
- 对局流量不走 MQTT
- 公共 broker 上的消息对知道频道名的人可见，请勿把隐私写进昵称
- 异常掉线会靠 MQTT Last Will 清掉在线状态
