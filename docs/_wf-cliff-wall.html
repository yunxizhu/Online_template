规则与操作
兵种图谱 锐士近战突进，攻守兼备 盾卫重甲缓慢，坚不可摧 游侠远程狙击，薄血长射 轰击范围炮击，落点成墨 燎原持续喷火；二级起落点留下灼烧地形 激光兵锁定越久伤害越高，最高 5 倍
地形 水域不可通行 山地不可通行，且有高度：挡住视线与弹道，山两侧互相看不见、打不到 平原一览无余 地图主题每局开局随机抽一张手工设计的地图（标准战场 / 壁垒 / 群山 / 汪洋 / 超级平原 / 千湖泽国 / 裂谷 / 棋盘街区 / 环形山）：山是笔直长墙、湖是规整方圆，长墙按间距留有关口；本局抽到哪张，标在左下角小地图标题旁 进攻主路每两个相邻玩家之间强制挖出上 / 中 / 下 3 条可通行大道，每条净宽 15 格以上（能并排走 7 个兵），任何地貌都不会只剩一条独木桥；路之间仍留着原有地形当分隔带 地势高低山是高地、水是洼地，等高线越密坡越陡、粗深的一道是过不去的崖；选中自己的兵会在地图上画出它的实际射程环——朝低处鼓出去（打得远，画暖金）、朝高处被削掉（打得近，画冷灰），环里那圈细虚线是不考虑地势时的射程，用它当尺子比一比就知道自己占了多大便宜。全程没有数字标注，看图即得
交战 不追击敌人进入攻击范围才开火；跑出范围即停火，部队绝不自己追出去 移动攻击行军途中照常开火，边走边打（不必停下） 索敌范围= 自身攻击范围，更远的敌人当作看不见 规划路径选中部队后按住 Shift + 右键 连续点地面 → 依次记下一串路点（画面上画出每段的行进线，路点带序号），松开 Shift 再右键点终点（或直接按回车）部队就按这条链依次走完；Esc 作废重来。绕开山水的走法与右键直走完全一致，中途路点只是「路过」，不会停下发呆 锁定攻击选中部队后右键点敌方 / 中立单位或建筑 → 下达追击命令：在射程内就直接打（哪怕旁边有更近的敌人），不在射程内就主动寻路赶上去，目标逃跑也一路追；右键别处（行军）/ 停止 / 目标阵亡才解除。执行中的部队与目标之间会有一条虚线指示 唯一的友伤只有燎原的灼烧地形会烧自己人：把火铺在自家部队脚下，掉血的是自己（一级燎原不留火场，所以只有二级起才烧得到自己）
战场识别 归属色红 / 蓝 / 黄 / 绿四方阵营色；单位脚下、工厂厂区、总部台基都压同色底盘（60% 透明），一眼看清是谁的 血量所有单位默认常显血条（满血也显示），颜色随归属方 选中效果被选中的部队脚下多一圈亮色呼吸光环，四周再加四角方框 开火开枪时枪口会喷出锯齿状的火星与硝烟，射手同时向后一顿（后坐）；燎原是一道往外泼的长火舌，激光兵是冷白细芒 弹道弹丸是沿弹道拖笔的墨滴（不是圆点），每发的笔锋都不一样；炮击弹更粗更沉（燎原不走弹道，是持续的火舌） 命中打中哪里就在哪里炸开一团不规则的墨（像水球拍在地上），带一圈飞溅 弹痕命中处在地上留一小块墨渍，约 9 秒后淡去——一眼看出这片区域刚被打过 灼烧地形燎原的火舌落在哪里，哪里就烧起一片暗红火场（范围很大）；踩在上面的单位持续掉血，不分敌我，火焰一停几秒内自行熄灭。一级燎原不留火场，进化到二级才会烧地，三级火场更大、烧得更久、伤害更高
指挥栏 小地图左下；点击或按住拖动即可把镜头跳到该处。地形一律灰化，只靠深浅分辨：最浅是平原、中灰偏冷是水体、最深是山体；部队与建筑不分四方阵营色，只看敌我——我方蓝、敌方红（中立是墨灰），每个点外还套一圈同色光晕 单位粗览中栏；只列当前选中的部队，没选中时这一栏不显示（想看谁就点谁） 侦察他家的部队 / 工厂 / 总部 / 研究所也能左键点开看数据——只读，没有升级与指令按钮；框选永远只圈自己的部队 单位详情右栏；点部队看属性，点工厂看产能，点总部看血量与产能升级 F2全选我方所有部队（F 只选镜头内） 滚轮在战场上滚动滚轮缩放视野；以鼠标所指位置为锚点，拉远看全局、推近看细节。缩放范围很宽：最远能一直拉到整张地图装进可见区（边上留一圈空），最近能推到贴脸看细节 中键平移按住鼠标中键在战场上拖动，地图跟着手走（浏览器自带的「中键自动滚动」已屏蔽，中键只用来拖地图） 空格镜头立刻回到自家总部（总部没了则回自家工厂；缩放倍率不变） 编队Ctrl / Shift + 数字键 0-9：把当前选中的部队编入该编号（没选中则清空该编号） 数字键 0-9选中该编队；同一编号连按两下，镜头立刻飞到编队的第一支部队（编队为空则不动）
工厂 兵种自选每条产线产什么兵由你定：开局第一条随机，之后再开辟产线时自己挑 产线工厂与总部默认各 1 条；花 300 科技点在面板里点「开辟产线」（先选兵种），最多再开 1 条（合计 2 条）并行生产 已开拓标识开拓过产线的建筑，模型右下方会多一枚明显简化的小模型（工厂＝屋顶折线加烟囱，研究所＝六边形环），一眼看出谁开过线 集结点左键点选工厂 / 总部 → 右键设集结点，此后新兵自动前往（Delete 清除）；总部与工厂操作完全一致 侦察工厂点敌方 / 中立工厂同样能看它的产线配置与产能（只读，没有按钮） 产线进化中 / 高级工厂的每条产线都能单独进化一阶：进化后这条线直接产出该阶单位，而不是继续产初级再一支支手动进阶。每个兵种只有一条进化路线 易主重置工厂被打下来后产线一并重置为「一条一级线」，高阶产线不会白送对手
科技 科技点左上角显示；只有占领研究所才产出——每座每 3 秒「一次性」+2 点（两座即每 3 秒一次 +4），HUD 进度条走满才跳，一座不占则为 0 统一 300开辟产线 / 产线进化 / 生产加速三样都是 300 科技点，不再是过去的六百 / 一千 产线进化每 300 科技点可让一条产线进化一阶（此后这条线一直产该阶单位）；总部产线不可进化 生产加速点选总部 → 花 300 科技点点「加速生产」；每次在当前生产间隔上再减 1/15（复利），最多 20 级 研究所初始中立，与工厂一样有血量：打光即由「最后一击者」接管并满血 研究产线占下研究所后，可在面板里花科技点点「开拓研究产线」（点击即生效，每所最多 4 条）；每条每周期产出 +1，建筑四周多一只研究罐 总部防卫总部自带一门炮：新索敌先蓄能（聚能球 + 蓄能弧走满），蓄满后按冷却突突连射；换目标会重新蓄能 总部每人一座、不可易主；自带一条产线（默认产锐士、不可进化），被打光即总部陷落，本人出局
出击 初始部队开局没有工厂，只在总部拥有 6 种初级单位各 1 支 总部面板左键点选自己的总部 → 右侧详情栏：看总部产线（默认锐士）、开辟新产线、加速生产

部队只打攻击范围内的敌人、不自动追击，但移动中照常开火 · 工厂与研究所有血量：打光即由「最后一击者」接管，易主后恢复满血，中立建筑只有 1/3 血 · 每条产线产什么兵自己定：点工厂 / 总部花 300 开辟产线（先选兵种，最多合计 2 条）· 中高级工厂每条产线花 300 进化一阶（此后直接产该阶单位，每个兵种只有一条进化路线）· 总部默认产锐士且不可进化 · 左键框选部队 · 右键移动 · Shift+右键 依次点路点规划路径（回车出发 / Esc 取消） · F 选取镜头内部队 / F2 全选我方部队 · 选中工厂 / 总部后右键设集结点 · 点总部花 300 加速生产（最多 20 级）· 点自家研究所开拓研究产线（每条每周期 +1，四周多一只研究罐）· WASD/方向键移动镜头 · 点击小地图跳转 · 总部被打爆即出局
