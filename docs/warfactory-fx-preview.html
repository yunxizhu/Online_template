战争工厂 · 特效图谱

直接用游戏里的作画代码（public/games/warfactory/ui.js → previewFx）逐格绘制，未另抄一份造型。 特效本身只有 170~560ms，无头截图很难卡到正在燃烧的那一帧，所以这里把相位也开成参数： 同一个特效在 age = 0 / 0.3 / 0.7 三档并排摆出来， 形状对不对、开火有没有「先张后收」一眼可辨。
每格下方的读数来自「把这一格真的画到离屏画布、再从中心沿 36 个方向打射线求边界半径」： 边界半径种数越多说明轮廓越不规则，正圆只会给出 1~2 种。

一、弹道：没有一处「规规矩矩的圆」

普通弹丸 = 归属色墨晕（底）+ 沿弹道拉长的墨滴（上）+ 身后三级收细的拖笔； 炮击弹 = 粗墨块 + 长拖尾 + 虚线影；燃烧弹 = 朱砂火星 + 飘忽火尾；近战 = 一道沿真实攻击方向的短挥痕。 同一弹种换一个个体种子，轮廓就该明显不重样。

二、开火：枪口焰要先张后收

  • ① 硝烟：往枪口反方向回卷的墨烟，炮击最浓；
  • ② 星芒：以朝向为中心、长短不一的锯齿尖刺（不是一圈等长的光斑）；
  • ③ 焰芯：外热内亮的双层墨团，激光是冷白芯。
  • 节奏：age=0 焰还没张开（亮度 0）→ age≈0.3 冲到最亮最张 → age=0.7 已经收回去大半。

三、命中：像水球拍在地上炸开

主体一团不规则墨先铺开，外围飞溅沿命中方向甩成扇面（不是四周等量均匀撒点），越远越小越淡。 归属色内芯固定 30% 不透明度 —— 不与「弹痕」那档混同。

四、炮击落点与地面弹痕

落点是墨花炸开 + 甩出去的泥点；弹痕是贴地的一小团墨渍 + 3 点固定飞溅（位置由种子决定，不逐帧乱跳）， 寿命 9 秒、后段淡得更快，避免整图糊成一片灰。

四·五、燎原：火舌落地（在落点铺开灼烧地形的那一下）

与「墨花炸开」刻意区分：没有飞溅的墨点，而是向上翻卷的火焰 —— 底下一圈焦痕，再往上窜几丛高低不一、左右摇摆的火苗（外红 → 内橙 → 白芯），随 age 越烧越淡。 火场本体由快照持续下发（火焰一停，几秒内跟着熄灭），这里只核对「刚点着」的爆发感与淡出节奏。

五、判定：不规则 ≠ 正圆
