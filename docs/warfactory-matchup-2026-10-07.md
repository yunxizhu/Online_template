## 七、克制要点（10v10 残血差，micro）

- **轰击** 压 锐士 +68 / 游侠 +65 / 燎原 +26 / 激光 +87；**唯一打不过的是盾卫**（−15）；

- **激光兵** 团战全负（−59 ~ −90），只在 1v1 里赢轰击（3 阶 0% : 47%）
  —— **1v1 结论不能外推团战**，这条再次验证。
- **无操作对冲（rush）时轰击几乎全负**：被贴进最小射程死角就停火，是「吃操作」的兵。

## 八、本轮两条规则改动

1. **子弹与子弹效果随进化变大**（激光的已实现，补齐其余兵种）
   - 服务端 `shot` / `hit` / `boom` 事件新增射手 `ty`（兵种）+ `ti`（阶数）。
   - 客户端：命中墨花、地面弹痕新增 `fxScaleOf(type, tier)`（弹体类取 `BULLET_TIER_MUL`
     `[1, 1.38, 1.76]`，火舌 / 激光束取更收敛的 `BEAM_TIER_MUL` `[1, 1.16, 1.32]`）；
     枪口焰本就按射手体型 `e.r` 长大（10 → 15 → 20px），不再重复放大。
   - `public` 与 `mobile` 两份前端同步；抛射弹的落点圈 / 地面阴影 / 弹体本体一并放大。
2. **攻速浮点残渣修复**（`updateUnits`）：`cdLeft` 累减会留下 6.9e-17 的残渣，
   「正好到点」那一帧判不出 `<= 0`，**所有兵种每次攻击都要多等一帧** ——
   cd 0.5s 实测变成 0.55s 一口，真实秒伤比 data.js 少一成。现在残渣按 0 处理，回到标称攻速。
   （推演台本来按标称算，所以这一步是让**服务端对齐推演台**，不是加强某一兵种。）

## 九、遗留建议

- 轰击弹速仍随阶**变慢**（440 / 360 / 280）：3 阶飞行 1.43s、敌人同期走 150px ≫ 溅射 55px，
  靠大溅射才勉强补回命中。若想让高阶轰击更稳，把弹速改成随阶**变快**（如 420 / 460 / 500）。
- 激光兵的定位与实测一致：**攻城特攻**（拆总部 / 拆工厂最快），野战与守家垫底，必须配前排。
